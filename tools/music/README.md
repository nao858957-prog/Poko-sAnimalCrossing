# ゲームの BGM（電子音版）

曲：「となりにいていいですか」（Suno で制作）の電子音（チップチューン）版を、ゲーム内で演奏しています。

- `make-score.py` … 曲の mp3 を自動で採譜して `js/bgm-score.js`（メロディ・コード）を作る（Basic Pitch 使用）
- `js/bgm.js` … 楽譜を電子音の楽器（三角波のリード（主旋律）を主役に、小さめのアルペジオ・ベル・ベース）で演奏する。
  セクションごとの楽器の入り方は `LAYERS` で調整（原曲の構成：ピアノだけ→ピチカート→ギター→木管→全員→グロッケン→ピアノだけ）
- `render-bgm.mjs` … ゲームと同じ演奏を wav に書き出す（動画づくり・確認用）

自動採譜なので、聴いておかしい音があれば `js/bgm-score.js` の `mel`（[16分の位置, 長さ, MIDIノート]）や `chords` を直接直せます。
