# ポコのちいさなしま 🐼

「ポコの小さな日々」の世界で遊べる、ブラウザ用の **あつまれどうぶつの森風** のほのぼの3Dゲームです。
3D は **three.js のみ**（`vendor/three.module.js` を同梱、ビルド不要）。

## あそびかた

- **スマホ**：左下のジョイスティックで移動／地面や動物を**タップ**して歩く／画面を**ドラッグ**でカメラ回転／右下の ◀ ▶ でも回転
- **PC**：矢印キー or WASD で移動、Enter／スペースで話す
- 動物に近づくと出る **「💬 〇〇と はなす」** でチャット。入力が大変なときは、下の**ボタン（話題）をタップ**するだけでも会話できます
- 島の花（🌼）を集めて、チャット中の 🌼 ボタンで友だちにプレゼント → なかよしレベル（♥）が上がる
- 丸太の家（セイママのおうち）の玄関から**室内**に入れます（暖炉・ソファ・ロッキングチェア・キッチン）
- 島の西にある **おみせ**（🛍）の入口に立つと、🌼 で **たべもの**（おだんご・ホットケーキ…）と **きせかえ**（ぼうし・マフラー・エプロン・マント）を買えます。食べると友だちもひとくち → なかよし度アップ
- しばらく何も操作しないか、メニューの「💤 ねる」で寝ると、**ポコ（と少しあとにメイ）が隣に来て一緒にごろん**。起きるとなかよし度アップ（画面をさわれば起きます）
- **なかよしレベル（6段階）**：はじめまして → かおなじみ → ともだち → なかよし → しんゆう → きずな。レベルで **呼びかた・あいさつ・話せる話題・おねがい** が変わります（初対面で頼みごとはされません。個人的な話や本音は、仲良くなってから）
- **ゆっくり育てる**：会話で増えるなかよしポイントは1日8まで。毎日少しずつ会いに来るのがコツです。プレゼントやおねがいなら、もっと仲良くなれます
- **プレゼントのこのみ**：チャットの 🌼 ボタンから、おはな・あつめもの・おみせの「もちかえり」を贈れます。キャラごとに「だいすき／すき／ふつう／にがて」があり、反応と上がり方が変わります
- **まいにちのごようきき**：ともだち（Lv2〜）になると、日替わりで小さな頼みごとをしてくれます
- **にっき**：できごと（おねがい達成・なかよしの節目・プレゼントなど）が日付つきで残ります。毎日最初に「きょうのおしらせ」が出ます
- **おねがい（ミッション）**：頭の上に **❗** が出ている友だちに話しかけると「おねがい」を頼まれます（あつめもの・おでかけ・よるの星空・おみせで買う・おひるね など、キャラごとの全35件＋毎日のごようきき。きずなレベルでは特別なきせかえがもらえます）。達成すると **❓** の友だちに報告して、🌼となかよし度がもらえます。上のバーと ☰ メニューの「📜 おねがいノート」で進み具合を確認できます
- **つり** 🎣：おみせ（ポン）の「どうぐ」でつりざお（きの🌼8／ぎん🌼25／きん🌼60）を買うと、ため池・みずうみ・うみのそばに「つりを する」ボタンが出ます。うきが沈んだら「いま！ つりあげる！」をタップ。場所・時間帯（夜だけの魚あり）・つりざおのグレードで釣れる魚が変わります（全28種＋ガラクタ）。釣った魚はおみせで売れ、友だちへのプレゼントにも（ナミ・クロは大好き）。☰「🎣 さかなずかん」で図鑑も見られます
- ☰ メニューの「🗺 マップ」で、島の全体・ともだち・目的地が見られます（島は広くなり、とうだい／ふうりんの神社／うみの家／みずうみ などのスポットがあります）
- ☰ メニューから **シアター**（3Dのミニストーリー8本）、**ともだちノート**、アバター変更、設定

## 40〜60代の方向けの配慮

- 大きな文字・大きなボタン（設定で「ふつう／おおきい／とても」）
- ひらがな中心、失敗やゲームオーバーなし、急かさない
- チャットは**ボタンをタップするだけ**でも成立（キーボード入力は任意）
- 「こえでよみあげ」（端末の音声読み上げ）、BGM の ON/OFF
- 時間帯は実際の時刻に連動（設定で朝・昼・夕・夜に固定も可）

## 途中でやめても再開できる

ブラウザの localStorage に **自動セーブ**（6秒ごと／会話後／アプリを閉じる時／メニューから）。
タイトルの「つづきから あそぶ」で、位置・アバター・なかよし度・花・会話履歴・設定がそのまま復元されます。
（同じ端末・同じブラウザで有効。ブラウザのサイトデータを消すとセーブも消えます）

## 公開（GitHub Pages）

リポジトリの **Settings → Pages → Build and deployment → Source: Deploy from a branch** で、ブランチ（`main` など）と `/ (root)` を選んで Save。
数分後に `https://<ユーザー名>.github.io/Poko-sAnimalCrossing/` で遊べます（スマホのブラウザでこのURLを開くだけ）。

## 起動方法

ES Modules を使うため、ファイルを直接開くのではなく簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages / 任意の静的ホスティングにそのまま置けば、スマホからURLだけで遊べます（ホーム画面に追加も可）。

## 管理者向け：アクセス解析

匿名の来訪数・遊んだ時間・機能の利用回数を、管理者だけが見られます（画面には出ません）。設定方法は [`docs/ANALYTICS.md`](docs/ANALYTICS.md) を見てください。

## 注意

- 画像・動画・音源の素材は使わず、モデルはすべて three.js の基本図形で作成しています。
- ブラウザの自動再生制限のため、BGM は最初のタップ後に始まります。iPhone は **マナーモード（消音スイッチ）がオン**だと音が出ないことがあります。左下の 🔊 ボタンやメニュー「せってい → おとの テスト」で確認できます。

## おうち・インテリア

- 島の西に「くらしのはま」があり、ポンのおみせの「おうち」タブでテント → こじんまりの おうち → おおきな おうち と建て替えられます。
- かぐ（28種）と かべがみ・ゆかのセット（7種）を買って、おうちの中の「おへやを かざる」で並べ替えできます（◀▲▼▶で移動、まわす、しまう）。
- 仲良しレベル2以上のともだちを、メニューの「おうちに しょうたい」で呼べます（テント1人／おうち2人／おおきな おうち3人）。
- お花はひろえる数・再出現を減らし、おみせの値段を上げてあります（`js/shop.js` / `js/fish.js` / `js/world.js`）。
