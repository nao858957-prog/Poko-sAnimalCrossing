## 実写パートの撮影・編集メモ

- **舞台**：丸太の家の室内（暖炉・ソファ・ロッキングチェア）が基本。明るい朝の光で、ゲームの色調（あたたかい色）に合わせます。
- **マッチカット**：イントロの最後に、スマホの画面にゲームのタイトル（または空撮）が映り、そのまま全画面に広がる。ゲーム映像の最初の白フェードを、画面の光とつなぎます。
- **切り返し**：ゲーム画面を見ているキャラの目線とリアクションだけを撮ります。画面の中は後から合成してOK（グリーン画面でも可）。
- **BGM**：ゲームのBGMを全体に通します。実写パートのセリフの下では −10〜−12dB まで下げます。
- **効果音の候補**：きらーん（スマホの光）、ぴくっ（釣りのあたり）、ぽちゃん、ケーン！（チャオ）、ぱちぱち（拍手）。
- **字幕**：ゲーム部分は焼き込み済み。実写のセリフは、下のSRTを重ねます（文字色はキャラ別がおすすめ：ポコ=黒、メイ=赤、セイママ=青、チャオ=緑）。
- **お花畑の大きな木**の場面は、セリフ・説明を入れず、BGMだけにします。

## 別案（セリフの差し替え）

- **イントロ（やさしめ）**：ポコ「きょうは とくべつな おしらせなの！」→ メイ「わたしたちの 島で、いっしょに 遊びましょ！」
- **アウトロ（セイママ中心）**：セイママ「のんびり、あなたの ペースで どうぞ」→ ポコ「ポコたちの ちいさな しま、まってるの！」→ みんな「いっしょに あそぼう！」
- **URL入りエンド**：独自ドメインが決まったら、エンドカードの文言を「あそびかたは 概要欄を みてね」→「（URL）」に差し替え（エンドカードは再撮影できます）。
