# ポコの世界観メモ（ゲーム制作用）

出典：チャンネル紹介文の改訂案、参照画像（キャラクター三面図・ログハウス内観）、
動画タイトル一覧・コメント（クリエイター本人の返信コメントを含む）。
※YouTube には直接アクセスできないため、共有いただいた資料から整理しています。

## 1. 作品の核

- 「ポコの小さな日々」＝**ユキヒョウが赤ちゃんパンダを育てる、血のつながらない家族のオリジナルアニメ**。
- 舞台は**森の小さなログハウス**。丸太の壁、ぬくもりのある灯り、暖炉、ベージュのソファ、
  ロッキングチェア、石の天板のキッチン、窓辺の観葉植物、壁にはパンダとユキヒョウの写真額縁。
- 季節がめぐるたびに小さな出来事が起こる：**七夕・お盆・初雪・お正月**ほか（花見、母の日、バレンタイン、クリスマス…）。
- 「難しいことは何もない。ただ見ているだけでほっとできる場所」。→ ゲームも急かさない・失敗がない・やさしい。

## 3. エピソードの断片（ゲームの会話・シアターに反映）

- 出会い：天敵のはずのユキヒョウ（セイ）が、命の危機にあった赤ちゃんパンダを拾う（異種母子）。
  「ぼくは、お母さんに似てない」と悩む回、ポコの実のお母さんとの再会、「お母さん」と初めて呼んだ日。
- 家族の日常：雪かき、お洗濯（雪は洗剤じゃない！）、餅つき、凧揚げ、ミトン編み、パンダ饅頭、冷やし中華「ぽこきん」、
  レモネード屋さん（お塩を入れちゃう）、スフレパンケーキ、おつかい、市場でカートが笹だらけ、温泉（浴衣が大きすぎて「ほぼ布」）。
- 寒い夜、離れて寝ていた3匹が暖炉の前で一つになる。
- ハルの物語：拾う → 名前 → 夜泣き → 初飛行 → 巣立ち。
- 母の日の花束の真ん中に笹が一本。セイの誕生日。高熱のセイを助けにメイとポコが「はじめてのおつかい」。
- 海の旅シリーズ（2026夏）：「海ってどんな味？」。風鈴の神社、灯台、海の家づくり、線香花火と夜光虫、ナミとクロとの出会い。
- 七夕：笹に願いごとをすると天の川から双子が降りてくる。お盆：天の川を渡ってきた友だち。

## 4. ゲームへの反映

- ログハウスの**外観**と、入れる**室内**（暖炉・ソファ・ロッキングチェア・キッチン・額縁）。
- 季節イベント（七夕の笹と短冊／お盆の提灯／初雪／お正月の門松）を実際の日付で自動表示（設定で切替可）。
- セイは「セイママ」。ポコ・メイは「〜なの」「〜なんだからね」。会話でエピソードを話題にできる。
- シアター：おひるね／宝さがし／ハルの帰郷／うみべ／ごはんに加え、ポコのお料理・七夕・初雪を追加。

## 5. 島の西側（くらしのはま）

- 本島の西に「くらしのはま」。プレイヤーのおうち（テント → おうち → おおきなおうち）、はたけ、「おもいでの おおきな き」がある。
- **おもいでの おおきな き**：ほらあなは、ポコを産んでくれた実母（今はもういない）が暮らしていた場所。まわりは一面のお花畑。静かで穏やかに扱う（仲良しレベルが高いと、ポコたちが少しだけ話してくれる）。
- **はたけ**：ニンジン／トマト／いちご／かぼちゃ。実際の時間で育つ。チャオが虫を食べて助けてくれるが、ときどき収穫前の野菜をつついてしまう（話しかければ止められる）。
