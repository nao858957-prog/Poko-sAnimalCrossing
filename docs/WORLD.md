# ポコの世界観メモ（ゲーム制作用）

出典：チャンネル紹介文の改訂案、参照画像（キャラクター三面図・ログハウス内観）、
動画タイトル一覧・コメント（クリエイター本人の返信コメントを含む）。
※YouTube には直接アクセスできないため、共有いただいた資料から整理しています。

## 1. 作品の核

- 「ポコの小さな日々」＝**ユキヒョウが赤ちゃんパンダを育てる、血のつながらない家族のオリジナルアニメ**。
- 舞台は**森の小さなログハウス**。丸太の壁、ぬくもりのある灯り、暖炉、ベージュのソファ、
  ロッキングチェア、石の天板のキッチン、窓辺の観葉植物、壁にはパンダとユキヒョウの写真額縁。
- 季節がめぐるたびに小さな出来事が起こる：**七夕・お盆・初雪・お正月**ほか（花見、母の日、バレンタイン、クリスマス…）。
- 「難しいことは何もない。ただ見ているだけでほっとできる場所」。→ ゲームも急かさない・失敗がない・やさしい。

## 3. エピソードの断片（ゲームの会話・シアターに反映）

- 出会い：天敵のはずのユキヒョウ（セイ）が、命の危機にあった赤ちゃんパンダを拾う（異種母子）。
  「ぼくは、お母さんに似てない」と悩む回、ポコの実のお母さんとの再会、「お母さん」と初めて呼んだ日。
- 家族の日常：雪かき、お洗濯（雪は洗剤じゃない！）、餅つき、凧揚げ、ミトン編み、パンダ饅頭、冷やし中華「ぽこきん」、
  レモネード屋さん（お塩を入れちゃう）、スフレパンケーキ、おつかい、市場でカートが笹だらけ、温泉（浴衣が大きすぎて「ほぼ布」）。
- 寒い夜、離れて寝ていた3匹が暖炉の前で一つになる。
- ハルの物語：拾う → 名前 → 夜泣き → 初飛行 → 巣立ち。
- 母の日の花束の真ん中に笹が一本。セイの誕生日。高熱のセイを助けにメイとポコが「はじめてのおつかい」。
- 海の旅シリーズ（2026夏）：「海ってどんな味？」。風鈴の神社、灯台、海の家づくり、線香花火と夜光虫、ナミとクロとの出会い。
- 七夕：笹に願いごとをすると天の川から双子が降りてくる。お盆：天の川を渡ってきた友だち。

## 4. ゲームへの反映

- ログハウスの**外観**と、入れる**室内**（暖炉・ソファ・ロッキングチェア・キッチン・額縁）。
- 季節イベント（七夕の笹と短冊／お盆の提灯／初雪／お正月の門松）を実際の日付で自動表示（設定で切替可）。
- セイは「セイママ」。ポコ・メイは「〜なの」「〜なんだからね」。会話でエピソードを話題にできる。
- シアター：おひるね／宝さがし／ハルの帰郷／うみべ／ごはんに加え、ポコのお料理・七夕・初雪を追加。

## 5. 島の西側（くらしのはま）

- 本島の西に「くらしのはま」。プレイヤーのおうち（テント → おうち → おおきなおうち）、はたけ、「おもいでの おおきな き」がある。
- **おもいでの おおきな き**：ポコを産んでくれた実母（今はもういない）が暮らしていた場所。木のまわりは一面のお花畑で、洞穴はかざり（中には入れない）。静かで穏やかに扱う（仲良しレベルが高いと、ポコたちが少しだけ話してくれる）。
- **はたけ**：ニンジン／トマト／いちご／かぼちゃ。実際の時間で育つ。チャオが虫を食べて助けてくれるが、ときどき収穫前の野菜をつついてしまう（話しかければ止められる）。

## ポコたちの 1日 (js/schedule.js)
- ポコ・メイ・セイママは ゲーム内の時刻で「そと / おうち / ごはん / ねんね」を切りかえる。
- ごはんの時間（時間限定イベント）：あさごはん 6:30–8:30 / おひるごはん 12:00–13:30 / おちゃの じかん 15:00–16:30 / ばんごはん 18:00–19:30。セイママの家に入っていると なかよし度ボーナス（1日1回ずつ）。
- ねる時間：ポコ 21:00・メイ 21:30・セイ 23:00 から 朝まで。ベッドで寝ていて、話しかけられない。
- おねがいの `hours: [開始, 終了]` を付けると、その時間帯だけ頼まれる。`type: 'meal'` はごはんの時間に家へ行くと達成。

## あきの イベント「もみじの きせつ」 (event = 'autumn')
- **期間**: 9/20〜11/30 は自動。設定「きせつの かざり」で「もみじ」を選べば いつでも。12〜2月は「ゆき」。
- **紅葉**: 木(はじめ島の木・おおきな き)が 赤/オレンジ/黄に。しばふは きいろっぽく。おちば(葉っぱの粒)が ひらひら ふる。
- **あつめもの**(あきだけ): 🍁もみじ・🌰くり が しまに おちている(`ITEMS.maple / chestnut`)。
- **さつまいも**: 🍠 たね(ポンのおみせ「どうぐ」タブ・あき/ふゆだけ)→ はたけ(20ぷん)。
- **たきび**: ひろば(`world.campfire`)に あき〜ふゆ だけ 出る。近づくと「🔥たきびで りょうり」。
  - `やきいも`(さつまいも1) / `やきぐり`(くり3) …… どうぐ `fire`(おうちの オーブンでも可)
  - くりごはん(セイ f2)・だいがくいも(メイ f2)・もみじのてんぷら(セイ f3)
  - 調理アクション `js/cookact.js` の `fire` シーン(ホイルに くるんで ほりこむ)
- **やきいもタイム**: 16:30〜18:00(あき・ふゆ)。ポコ・メイ・セイ・パ・ク・ナミ・クロが たきびに あつまる。
  この じかんに やきいも/やきぐりを つくると、まわりの みんなと わけっこ(なかよし +2)。
- **あきふゆコーデ** (`js/shop.js` の `season: true`): どんぐりぼうし・もみじのかんむり・ベレー・みみあて・しろいポンポンニット・
  ベージュのマフラー・もこもこえりまき・くりいろカーディガン・からしいろのポンチョ。あき/ふゆの あいだだけ おみせに ならぶ(かった ものは ずっと もてる)。
- **おねがい**: ポコ「やきいもを つくろう」/ メイ「もみじを あつめて」/ ポン「くりを さがしてぽん」「あきふゆコーデを みせてぽん」(`season` ではない ときは かくれる)。

## 常連さん向けの会話 (js/fans.js)
- 名前に `FANS[].k` のことばが含まれていると、ポコ・メイ・セイママ（ほかのともだちは共通の一言）が特別な言葉をかける。
- `topics`: その人だけの話題（例: あおいほしぞらさん→中国のパンダ・旅・赤ちゃんパンダ）。`more`: 毎日変わる一言。
- `NEWS`: **最近の動画の話題**。`from/to` の期間だけ有効。常連さんと話すと、毎日1本ずつ（キャラごとに）話題にし、
  「さいきん どう？」「どうが みたよ」「柿」「十三夜」など動画に関わる言葉にも反応する。**新しい動画が出たら NEWS に1件足す**（古い順に自動で消える）。
- 動画一覧・コメントの元データ: 共有スプレッドシート「動画コメント分析シート」。

## どうがへの リンク (js/videos.js)
- メニュー「📺 ポコたちの どうが」: 最新8本のサムネ付きカード → YouTube。チャンネル登録リンクつき。タイトル画面にも「ポコの どうがを みる」。
- 会話: 「どうが みたいな」チップ、または「動画/youtube」を含む言葉 → キャラが紹介して動画カードを出す。常連さんには最近の動画の話題（NEWS）に動画カードがつく。
- **新しい動画が出たら** `VIDEOS` の先頭に1行（id=URLの v= の後ろ）。常連さん向けは `js/fans.js` の `NEWS` に `vid` つきで1件。
- 集客の計測 (GoatCounter のイベント): `video-menu` / `video-click` / `video-<動画ID>` / `video-channel`。
