## 3. あそびかた動画（約6〜7分・横）

### タイトル（どれか1つ）

1. **【あそびかた】ポコの ちいさなしま 操作・設定・データのひきつぎ方まで やさしく解説**（おすすめ）
2. 【はじめての方へ】ポコの ちいさなしま あそびかたガイド｜スティックの動かし方・おねがい・ひきつぎコード
3. ポコが教える ゲームのあそびかた🐼 スマホ操作・設定・セーブの引き継ぎ

### 概要欄

```
ポコが、ゲーム「ポコの ちいさなしま」のあそびかたを、いっしょに見ていきます。
スマホでも、パソコンでも遊べます。むずかしくないので、のんびりご覧ください。

▶ あそぶ：https://pokos-little-days.com

【もくじ】
0:00 ごあいさつ
0:17 ① はじめかた
0:45 ② あるく（スティック・タップ）
1:15 ③ おはなをひろう
1:33 ④ ともだちとおはなし・プレゼント
2:14 ⑤ ともだちのおねがい
2:51 ⑥ ポコたちの1日（ごはん・お茶の時間・ねんね）
3:31 ⑦ おみせ・つり・はたけ
4:05 ⑧ じぶんのおうち
4:24 ⑨ ねる・おきる
4:43 ⑩ せってい（文字の大きさ・おと）
5:18 ⑪ ひきつぎコード（きろくのうつしかた）
6:09 おしまい

【大事なお知らせ：データのひきつぎ】
ゲームの記録は、いま使っているブラウザの中に保存されます。
機種をかえたり、ブラウザの記録を消したりすると、消えてしまうことがあります。
そんなときのために、メニューの「ひきつぎコード」で、記録をうつせます。
（コードをつくる → ぜんぶコピー → メモアプリなどに保存）

#ポコの小さな日々 #ブラウザゲーム #あそびかた

（ここに「共通：クレジット欄」を貼り、あそびかた動画用の追加分も入れる）
```

> ※ もくじの時間は、ナレーションなしの映像の長さです。音声を入れて長さが変わったら、実際の動画の時間に直してください（YouTube は「0:00 から始まる」「3つ以上」「時間が昇順」の形式でないと、もくじとして認識されません）。

### 設定メモ
- 年配の方が多い想定なので、**字幕（キャプション）をオン**にして、自動字幕ではなく台本（`docs/tutorial-script.md`）から作ると正確です。
- 再生リスト「あそびかた」を作って入れると、見つけてもらいやすくなります。
- ナレーションは音声合成なので、**「合成されたコンテンツ」は「はい」**にしておくと安全です。
