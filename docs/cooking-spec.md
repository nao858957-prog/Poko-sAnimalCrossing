# 料理システム 仕様案（たたき台）

「畑の野菜・島のもの・ポンの店の食材 → おうちで料理 → 食べる／友だちに贈る／ごはんの時間に出す」の循環を足す案です。
**まず仕様を決めるための資料**で、まだ実装していません。★は「決めてほしいところ」（巻末に質問をまとめています）。

---

## 1. コンセプト

- **ゆっくり・失敗なし・簡単操作**（40〜60代向け）。タップ数は「料理を選ぶ → つくる」の2回が基本。
- **おうちを育てる意味づけ**：おうちの大きさ（テント → こじんまり → おおきな家）で、使える道具と作れる料理が増える。
- **畑・お店・友だち・ごはんの時間と全部つながる**：作った野菜が使える／食材はポンの店／レシピは友だちから／料理はごはんの時間やプレゼントで活きる。
- 既存の仕組み（お花 🌼、なかよし度、プレゼントのこのみ、ごはんの時間、おねがい、引きつぎコード）をそのまま使う。

## 2. 全体の流れ

```
①食材をそろえる ─ 畑の野菜 / 島で拾うもの / 釣った魚 / ポンの店「しょくざい」
        ↓
②レシピを教わる ─ セイママ・メイ・ほか友だち（料理レベルとなかよし度が条件）
        ↓
③おうちで料理 ─ 家の「調理道具」で作れるものが決まる（家のサイズ制限）
        ↓
④できあがり ─ 食べる(近くの友だちがひとくち) / 友だちに贈る / ごはんの時間に出す / 売る
        ↓
⑤料理レベルが上がる → 新しいレシピ・道具・同時調理が解放
```

- 野菜などの収穫物は、これまで「友だちへのおくりもの」だったが、料理の材料としても使える。

## 4. 家のサイズと調理道具（このシステムの目玉）

調理道具は「かぐ」として置く（既存の「おへやを かざる」）。**家の大きさ（段階）に満たないと置けない**。

| 家の段階 | 置ける調理道具 | できる料理の種類 |
|---|---|---|
| **テント**（段階1） | **キャンプ用シングルバーナー**（新・かぐ） | ゆでる・あたためる（スープ・ゆで野菜・ハーブティー・おかゆ）。1品ずつ |
| **こじんまりの おうち**（段階2） | ミニキッチン（既存）／まきストーブ（既存）／まな板（新） | いためる・やく（たまごやき・おにぎり・しおやき）、にこむ（にもの・シチュー） |
| **おおきな おうち**（段階3） | オーブン（新）／システムキッチン（新・コンロ2口） | やく（ケーキ・パン・クッキー・グラタン・パイ）。**2品同時**・まとめ作り |

- テントにミニキッチンを置こうとすると「テントでは せまくて おけないよ」と表示（道具の「必要な家の段階」を設定）。
- すでにテントに置いてしまっているキッチンなどは、**そのまま置いたままでOK**（壊さない）。
- セイママのおうち（ログハウス）には、全部そろった台所がある。**セイママと一緒に作る**モードで、教わった直後の初回調理と、お手伝いイベントができる（★）。

## 8. 調理の操作と画面

1. おうちに調理道具があれば、メニューや画面のボタンに「🍳 りょうりする」が出る（おうちの中で道具に近づく、または下のボタン）。
2. **料理の一覧**：作れるもの（明るい）／材料が足りない（材料の不足を表示）／道具が足りない（「おおきなおうちが ひつよう」など）／まだ教わっていない（「？？？」）を色分け。絵文字つき・大きなボタン。
3. 「つくる」を押す → 材料が自動でセットされる。数秒のアニメ（湯気・ぐつぐつ音・チーン）→「できあがり！」。
4. 待ち時間（★）：基本はすぐできあがり。**煮込み・オーブン系だけ、畑のように実時間で数分かかる**（放置でも進む）案。
5. 同時に作れる数は道具の数と料理レベルで決まる（バーナー1・コンロ1・オーブン1、システムキッチンは2口）。

## 9. できあがった料理の使いみち

- **食べる**：近くの友だちがひとくち → なかよし度アップ（今のお店の料理と同じ）。
- **友だちに贈る**：プレゼント画面から。友だちごとの好み（だいすき／すき）を料理にも拡張。★が高いほど喜ぶ。1日のなかよしポイント上限の扱いは今のプレゼントと同じ。
- **ごはんの時間（朝・昼・お茶・夕）**：セイママのおうちに**料理を持ち寄る**と、みんなが食卓に出して食べる。ボーナスが大きい。
- **おうちに招待した友だち**に出す：ごちそうさまのやりとり＋なかよし度。
- **おねがい**：「〇〇を つくってきて」の納品型を追加（セイママ・メイ・ポン・チャオ・クロ・ナミ…）。
- **売る**：ポンに売る（お花）。材料費より少し高くなるように調整。
- **料理ずかん**とにっき：作ったことが記録に残る。

## 10. データと互換性

- セーブ：`S.cook = { lv, xp, recipes:[], made:{id:{n,best}}, pantry:{}, dishes:{}, pots:[] }`。**古いセーブ（料理なし）でも壊れないよう、無ければ初期化**。
- 引きつぎコード：料理のデータも入れる（コードが長くならないよう、カテゴリ番号と個数だけに圧縮）。
- 既存の「お店で買った食べ物」の保存データ（`S.food`）は壊さず、料理は別の入れ物にする（統合は後で）。
- かぐの追加：バーナー・まな板・オーブン・システムキッチン。既存の「ミニキッチン」「まきストーブ」に「必要な家の段階」を付ける。

## 11. 作る順番（段階）

| 段階 | 内容 |
|---|---|
| **第1段階（最小で遊べる形）** | 「しょくざい」タブ／レシピ 10〜12 品／道具3段階（バーナー・コンロ・オーブン）と家の段階制限／料理レベル 1〜3／セイママ・メイのレシピ／料理を食べる・贈る／セーブ・引きつぎ対応 |
| **第2段階** | 料理ずかん／できばえ★／待ち時間つきの煮込み・オーブン／おねがいの納品型／ごはんの時間に持ち寄り／全 20 品・料理レベル 5／季節限定／ナミ・クロ・ポンなどの先生 |
| **第3段階（おまけ）** | セイママと一緒に作る（調理イベント）／料理のバフ（食べると少し効果：釣りが少し楽・花ひろいが少し広い 等）／ポコの料理ミニアニメ／さつまいも・たまねぎなどの野菜追加 |

## 12. 注意点（作るときの懸念）

- `main.js` が大きくなるため、料理は別ファイル（`js/cook.js`）にまとめて、`main.js` からは呼び出すだけにする。
- バランス：お花のインフレ（最近調整したばかり）に注意。材料費・売値・なかよし度の上がり方は表で調整できる形にする。
- 家具が増えるので、モデルは既存と同じ「基本図形で作る」方式で軽く保つ。
- 画面が混み合わないよう、料理画面は「大きなボタン・少ない手順・戻るボタン固定」にする（おねがいノートと同じ作り）。

## 決めてほしいこと（おすすめ案つき）

1. **調理の待ち時間**：全部すぐ完成（かんたん）か、煮込み・オーブンだけ実時間（畑と同じ楽しみ）か。→ **おすすめ：基本はすぐ、煮込み・オーブン系だけ数分待ち（第2段階から）**
2. **できばえ（★1〜3）** を入れるか。→ **おすすめ：第2段階で入れる（最初は★なしで簡単に）**
3. **お店で今売っている料理**は残すか。→ **おすすめ：残す（初心者向け・★1扱い）**
4. **テントで作れる範囲**：バーナーは「ゆでる・あたためる」系だけでよいか（焼く系は家が必要）。→ **おすすめ：その通り**
5. **セイママのおうちの台所**で、自分で料理できるようにするか。→ **おすすめ：セイママと一緒のときだけ（レシピを教わる流れ）**
6. **食べたときの効果**：なかよし度だけか、短時間のバフ（釣りがやさしい等）も付けるか。→ **おすすめ：最初はなかよし度だけ。バフは第3段階の候補**
7. **最初のレシピ数**：10〜12品で始めるか、最初から20品か。→ **おすすめ：12品で始めて、アップデートで増やす（「また新しいレシピが増えたよ」で再訪の理由にもなる）**
