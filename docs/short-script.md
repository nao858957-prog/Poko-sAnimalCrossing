構成：**実写風イントロ（4.5秒）＋ ゲーム映像（35.5秒）＋ 実写風アウトロ（5秒）＝ 45秒**
ゲーム映像は `ポコ_ショート_ゲーム部分.mp4`（1080×1920 / 30fps / ゲームのBGM入り）。
※ゲーム映像の字幕は映像に焼き込み済みです。

読む速さの目安：1秒に 6〜7音（ポコ・ナミ系は元気に少し速め、メイは早口になりすぎないように）。

## 編集メモ

- BGM はゲームのものをそのまま使えます。セリフがかぶるところは −10〜−12dB 程度に下げてください。
- ゲーム映像の最初と最後はフェード（白）で始まり・終わるので、実写パートとは白フラッシュ→クロスフェードでつなぐと自然です。
- 効果音（SE）の候補：イントロ「ぱちぱち」、釣りの当たり「ぴくっ」、チャオ「ケーン！」、エンド「きらーん」。
