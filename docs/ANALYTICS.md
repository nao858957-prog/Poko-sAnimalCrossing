# アクセス解析（管理者用）

「どれくらいの人が、どれくらい遊んでくれているか」を、**管理者だけ**が見られるようにする仕組みです。
ゲーム画面には何も表示されません。無料の [GoatCounter](https://www.goatcounter.com/)（Cookie を使わない、匿名の集計サービス）を使います。

## セットアップ（5分）

1. https://www.goatcounter.com/signup で、無料アカウントを作る（「サイトコード」を決める。例：`poko-island`）。
2. `js/config.js` の `goatcounter: ''` に、そのコードを入れる。
   ```js
   export const ANALYTICS = { goatcounter: 'poko-island' };
   ```
3. コミットして公開（GitHub Pages）すれば、集計が始まります。
4. 集計は `https://poko-island.goatcounter.com` を**ログインして**見ます。
   - 管理画面の Settings → 「Allow adding visitor counts / Make this site public」などの**公開設定はオフのまま**にしてください（オフなら、管理者以外には見えません）。

空のままにすると、解析は一切動かず、通信も発生しません（ゲーム内の説明文や設定項目も自動で隠れます）。

## 見られるもの

| 知りたいこと | 見かた |
|---|---|
| 何人が来たか | ダッシュボード上部の「訪問者数／ページビュー」。日・週・月の推移、国/地域、ブラウザ、画面サイズ（スマホ比率）も出ます |
| どれくらい遊んだか | イベント `event/play-1min`・`play-5min`・`play-15min`・`play-30min`・`play-60min` の回数（それだけ遊んだ人の数） |
| 何人が始めたか | `event/new-game`（はじめから）、`event/continue`（つづきから＝リピート） |
| 何日も来てくれているか | `event/return-day2`・`day3`・`day7`・`day14`・`day30`（ゲーム内の何日めまで来たか） |
| どの機能が人気か | `event/chat`・`shop`・`fishing`・`theater`・`quest-done`・`levelup` |

各イベントは **1回の訪問につき1回**だけ数えます（＝その機能を使った人の数に近い値）。
「遊んだ時間」は、画面が表示されていて、1分以内に操作があった時間だけを数えています。

## プライバシー

- 名前・会話・セーブデータ・位置情報などは**一切送りません**。送るのは上の表の「回数」と、ブラウザの種類・画面サイズ・参照元のみです。
- 端末のブラウザが「トラッキング拒否（Do Not Track）」の場合は送信しません。
- 遊ぶ人は、ゲーム内の「せってい」→「つかいかたの とうけい」で、いつでもオフにできます。
- タイトル画面と設定に、統計を取っている旨を小さく表示しています（解析を有効にしたときだけ）。

## 別の方法（参考）

- Google Analytics 4 や Cloudflare Web Analytics に変える場合は、`js/analytics.js` の `send()` を置き換えるだけで済みます（イベント名はそのまま使えます）。
- 本格的な「ユーザーごとの継続率」などが必要なら、Firebase / Supabase などのバックエンドが必要になります（アカウント作成が必要）。
